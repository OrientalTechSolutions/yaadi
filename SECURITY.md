# Security

Please report a vulnerability privately through GitHub: https://github.com/OrientalTechSolutions/yaadi/security/advisories/new. Do not open a public issue.

Milestone 1 ships no phone build. The threat model and what is verified so far are in [ARCHITECTURE.md](ARCHITECTURE.md), sections 6 and 20. The web demo is not encrypted by design: it keeps made-up data in the browser tab and says so on every screen.
